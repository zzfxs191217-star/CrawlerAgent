# 选题指南：怎样让 CrawlerAgent 分析更成功

CrawlerAgent 的“发现层”基于白名单可信媒体（科技/AI 向）的 RSS 关键词检索，选题直接影响成功率。本文帮你把“容易失败的课题”改造成“容易成功的课题”。

## 一、成功率自检清单（开跑前过一遍）

- [ ] 这个话题在最近 1-2 周有没有媒体报道？（用「选题助手」预检）
- [ ] 对比对象是否控制在 2 个以内？
- [ ] 用的是官方产品名吗？
- [ ] 关键词里没有大而空的词（市场/竞争/分析…）？

## 二、好选题 vs 差选题

| 维度 | 好选题 | 差选题 |
|---|---|---|
| 热度 | 近期媒体持续报道（豆包 vs 通义千问） | 冷门领域（QQ音乐 vs 网易云 vs 汽水音乐） |
| 对象数量 | 2 个对象对比 | 一次对比 3 个产品 |
| 命名 | 官方产品名（网易云音乐） | 俗称/别名（网抑云） |
| 覆盖 | 白名单媒体会报道（科技/AI/文娱/消费，IT之家/娱乐资本论/品牌星球等已接入） | 完全冷门、无媒体长期报道的领域 |

## 三、选题公式

```
分析 <实体A> 与 <实体B> 的竞争态势
```

示例：
- ✅ 分析字节跳动旗下豆包与阿里通义千问的竞争态势
- ✅ 分析 DeepSeek 与 Qwen 的开源策略差异
- ❌ 腾讯的QQ音乐、网易云音乐、汽水音乐的市场竞争分析（3 个对象 + 冷门 + 泛词）
- ❌ 哪个 AI 助手更好用（无具体实体、泛词）

## 四、如果预检说“没料”

1. 换更热点、更被媒体关注的方向；
2. 3 个对象拆成 2 个，先做最核心的一对；
3. 换官方产品名，单独搜每个产品；
4. 数据源扩展已部分落地：IT之家/机核/Solidot 已入发现层，娱乐资本论/品牌星球/IT之家等已入内容层白名单，音乐/文娱/消费类课题覆盖面已改善；但无官方 RSS 的站点仍无法被自动发现，极端冷门课题建议换热点方向或官方产品名再试。

## 五、进阶技巧

- 用 Web 界面的「选题助手」页签预检，有料再点“去生成报告”；
- 命令行预检：`uv run python -m crawler.topic_check --topic "课题"`；
- 一个产品名单独搜更容易命中；
- 参考 `reports/` 里已成功的报告，模仿其课题写法。
